# 📖 求职知识库 · 日常操作指南

## 每日/每周要做的事

### 🔍 搜集岗位（阶段1）
1. 去 BOSS直聘/猎聘/应届生求职网搜 JD。
2. 把 JD 原文复制下来，发给 AI 打分。
3. 收到分数后，在 `01_岗位搜集与背调` 文件夹新建笔记，使用 Templater 模板 `岗位笔记模板`。
4. 填入 AI 给的分数和 JD 摘要。
5. 回到 `📋 岗位汇总表`，确认数据已自动出现。

### 📋 状态流转规则
| 动作 | 更新哪个字段 |
| :--- | :--- |
| 完成背调报告 | 当前状态 → `✅ 已背调`；背调报告 → `[[背调报告-xxx]]` |
| <70 分（未触发红线） | 当前状态 → `🗂️ 备选`（可试可不试，你决定） |
| 触发红线 | 当前状态 → `❌ 已挂（红线）`（不建议投递） |
| 完成简历定制 | 当前状态 → `📮 待投递`；定制简历 → `[[文雪_xxx-xxx]]` |
| 已投递 | 当前状态 → `✉️ 已投递` |
| 收到面试 | 当前状态 → `📞 面试中` |
| 被拒/放弃 | 当前状态 → `❌ 已挂` |

### 📝 面试后复盘（阶段5）
1. 在 `04_实战复盘` 新建笔记，命名为 `面试复盘-公司-岗位-日期`。
2. 记录：面试问题、自己的回答、面试官反馈、改进点。
3. 回到岗位笔记，将复盘笔记链接加入备注区。

## 🛠 遇到问题怎么办
- 执行 Skill 过程中出现的任何问题（工具异常、规则缺口、数据/文件/链接异常等），AI 会自动记录到 `99_系统与规则/求职知识库问题日志.md`（问题/原因/处理/状态）。
- 如发现日志缺失或想补充历史问题，直接提醒 AI 补充即可。


## 📎 原始材料归档
- 你提供的所有材料（JD PDF/截图/文本/链接）会自动归档到 `07_原始材料库/{公司}/{岗位}（{方向}）/`。
- 每份材料有登记笔记（来源/日期/关联岗位），汇总见 `07_原始材料库/📋 材料索引.md`。


## 🤖 自动岗位监控（Skill 7）
- 默认**每天 12:00** 自动执行：检索 → 去重 → 归档 → 评分 → 背调 → 生成「岗位日报」（需电脑开机且 Codex 应用运行）。
- 日报三档：✅推荐（≥70）/ 🗂️备选（<70 可试）/ ❌红线（不建议，仍列出）。
- 需登录的平台会请求你授权或粘贴 JD；公开可访问的直接抓取。
