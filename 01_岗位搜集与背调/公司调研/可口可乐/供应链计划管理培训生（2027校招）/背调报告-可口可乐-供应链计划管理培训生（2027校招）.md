# 一、公司基本面

## 1.1 一句话简介

全球最大饮料公司之一，2025 年营收 479.41 亿美元；中国业务为"上海总部 + 太古可口可乐 / 中粮可口可乐两大装瓶体系"的合资运营模式。

## 1.2 财务数据（2025 全年，公开检索）

| 指标 | 数值 | 同比 |
| :--- | :---: | :---: |
| 全球营收 | **479.41 亿美元** | +2% |
| 净利润 | **131.37 亿美元** | +23% |
| 四季度营收 | 118.22 亿美元 | — |
| 中国业务 | 坚定在华投入 | 装瓶体系（太古/中粮）运营 |

## 1.3 业务结构

饮料制造与装瓶（太古可口可乐、中粮可口可乐）｜供应链计划｜物流配送｜市场营销；快消行业（行业偏好加分）。

> 📌 **核心结论**：全球龙头、财务稳健（利润 +23%）、快消供应链体系成熟；但中国为"可口可乐公司 + 装瓶厂"合资结构，管培生签约主体（可口可乐本部 vs 太古/中粮装瓶厂）直接影响待遇、培养与晋升，须重点确认。
> ✅ **推荐点**：外企快消 + 供应链计划对口 + CPS 计划智能化改造项目（数字化）+ 行业偏好加分。
> ⚠️ **需要注意**：工作城市未披露（很可能上海）；装瓶体系口碑分化（太古"压力大、加班多"、中粮山东厂"双休福利好"），需确认供应链岗归属不受销售/市场岗"单休加班"影响。

# 四、针对文雪的风险和顾虑

## 4.1 工作城市未披露（很可能上海）

**为什么是问题**：文雪偏好济南/青岛、生活成本适中，北上广节奏快成本高。
**如何验证**：投递/面试确认 base 城市、办公地点、房补/通勤政策；若为上海需评估生活成本与是否接受。

## 4.2 管培生签约主体（可口可乐 vs 太古/中粮装瓶厂）

**为什么是问题**：本部与装瓶厂在薪资、培养、晋升通道上差异明显，"可口可乐管培"名头不等于本部编制。
**如何验证**：问劳动合同签约主体、社保缴纳主体、培训由哪套体系组织。

## 4.3 英语要求可能高于 CET-4

**为什么是问题**：外企系统/文档/汇报常含英文。
**如何验证**：问工作语言、系统界面语言、英文汇报频率；提前用知识库英语术语卡补强。

## 4.4 快消计划复杂度与节奏

**为什么是问题**：SKU 多、促销复杂，需求波动大，计划岗压力高于一般制造业。
**如何验证**：问计划团队人数、负责品类/SKU 规模、月末/旺季节奏。

## 4.5 装瓶体系口碑分化（太古 vs 中粮）

**为什么是问题**：同为可口可乐体系，不同装瓶厂口碑差异大。
**如何验证**：确认具体装瓶厂归属，检索对应厂员工口碑（贴吧/职Q/知乎）。

## 4.6 无大厂实习经历

**为什么是问题**：外企管培面试可能追问实践履历。
**如何验证**：主动呈现课程项目（4.5 万条数据分析 + 优化模型）与用友 U8+ 实操，证明"数据 + 计划"上手快。

## 4.7 "14 万/年"的口径

**为什么是问题**：14 万/年是纯月薪×12 还是含奖金/福利，直接影响实际到手。
**如何验证**：问薪资结构（基本/绩效/年终）、试用期薪资、加班费基数。
