# 一、公司基本面

## 1.1 一句话简介

全球新能源汽车销量第一的制造业龙头，业务覆盖汽车、动力电池、电子、半导体、轨道交通与光伏储能。

## 1.2 财务数据（2025年报）

| 指标 | 数值 | 同比 |
| :--- | :---: | :---: |
| 营业收入 | **8039.65 亿元** | +3.46% |
| 归母净利润 | **326.19 亿元** | -18.97% |
| 扣非净利润 | 294.46 亿元 | — |
| 基本每股收益 | 3.58 元 | — |
| 员工规模 | 86.96 万人（2024 年末 96.88 万） | 净减少约 10 万 |

## 1.3 业务结构

整车（第十一事业部等）｜动力总成（第十四事业部/原弗迪动力：电机、电控、发动机、电驱、车桥）｜电池（弗迪电池）｜电子｜半导体｜光伏储能｜轨道交通。2025 年 12 月组织架构调整，撤销第十三事业部（车灯）。

> 📌 **核心结论**：体量全球第一、现金流与研发投入雄厚（研发投入远超净利润），但 2025 年出现上市以来首次大规模减员（约 -10 万人）且利润同比下滑，属"龙头扩张放缓、内部提效"阶段。

> ✅ **推荐点**：济南基地为山东重要产能基地（起步区"汽车城"），电控业务落地济南，岗位属地稳定、本地通勤。
> ⚠️ **需要注意**：减员主体虽是生产人员（-9.72 万，占 97.9%），但需在面试中确认计划岗所在部门编制与稳定性。

# 二、岗位专项深度调研

## 2.1 JD 翻译成人话

| JD 原文 | 人话解读 |
| :--- | :--- |
| 分析历史数据与市场趋势，制定主生产计划 | 用历史销量/需求数据做产能-需求平衡，排定生产量，核心是"别缺货也别积压" |
| 细化日/周生产排程，分配人力设备物料 | 把计划落到产线每天/每周，协调人、机、料，执行导向、琐碎但关键 |
| 动态调整安全库存水位 | 根据物料采购周期和需求波动，管库存水位，是供应链计划核心技能 |
| 分析计划执行瓶颈，提流程改进 | 用数据找瓶颈、提优化建议，数据敏感度是加分项 |

## 2.2 岗位挑战

1. 产线计划节奏快、需求波动大（新能源车销量波动），要在缺货与积压之间反复权衡；
2. 与生产、采购、销售多部门博弈，沟通协调量大，但计划岗以数据说话，可扬长避短；
3. 需熟悉 ERP/APS 等系统与物料主数据，数据准确性决定计划质量；
4. 制造端若赶产量，计划岗可能被牵连进加班节奏（需面试核实）。

## 2.3 晋升路径（推测）

计划专员 → 资深计划/计划主管 → 计划经理/供应链经理；或横向转需求计划、库存计划、供应链分析岗。
标注：**推测**，基于行业惯例与比亚迪公开培养体系（事业部轮岗 + 明日之星）。

# 四、针对文雪的风险和顾虑

## 4.1 制造端加班强度不确定

**为什么是问题**：文雪拒绝 996、偏好从容节奏，产线计划岗加班风险高于研发岗。
**如何验证**：面试直问"部门平均下班时间/加班频率/调休政策"；脉脉/牛客找同事业部员工确认。

## 4.2 2025 年首次大规模减员 + 利润下滑

**为什么是问题**：大厂"提效收缩"期，新人的编制稳定性与培养资源可能受影响。
**如何验证**：问 HR 该岗位是新增编制还是补员、部门近一年人员流动率。

## 4.3 国内民企大厂 vs 外企优先偏好

**为什么是问题**：文雪公司类型排序为外企＞成长型中厂＞大厂，比亚迪属第三档。
**如何验证**：自问对该岗位的内容吸引力是否足以覆盖公司类型偏好；面试了解团队氛围是否"狼性"。

## 4.4 无大厂实习，面试易被质疑

**为什么是问题**：985 专业对口但缺大厂履历，计划岗面试官可能追问实践。
**如何验证**：主动呈现课程项目（4.5 万条数据分析 + 选址路径优化模型）与用友 U8+ 全流程实操，证明"上手快"。

## 4.5 "精益生产"与计划原理深度

**为什么是问题**：JD 明确"了解精益生产者优先"，文雪课程有覆盖但非专精。
**如何验证**：面试前补精益生产（看板/JIT/节拍）概念，准备一个结合案例的理解。

## 4.6 工作语言与系统环境

**为什么是问题**：大厂系统/文档可能含英文，文雪英语仅 CET-4。
**如何验证**：面试问"日常工作语言、系统界面语言、是否有英文汇报"。

> ⚠️ **额外关注**：面经显示比亚迪校招一面会问父母情况、期望薪资、是否独生子女等个人问题，需提前准备得体回答；济南基地具体办公点（起步区/济阳）通勤距离与班车需确认。
