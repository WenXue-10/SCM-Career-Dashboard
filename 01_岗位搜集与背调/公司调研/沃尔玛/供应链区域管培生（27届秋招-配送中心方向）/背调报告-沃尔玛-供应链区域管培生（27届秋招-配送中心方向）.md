# 一、公司基本面

## 1.1 一句话简介

全球最大零售商，中国区以山姆会员店 + 大卖场 + 电商/配送中心构成；山姆为中国区绝对增长引擎。

## 1.2 财务数据（中国区）

| 指标 | 数值 | 说明 |
| :--- | :---: | :--- |
| 中国区净销售额（2026财年） | **247 亿美元（约 1702 亿元）** | 同比 +21.7%，连续 3 年双位数高增 |
| 山姆全渠道销售额 | **1400 亿元** | 占中国总营收 80%+；单店年均超 22 亿元 |
| 山姆门店 | 63 家（2025 新开 10 家，入华以来纪录） | 付费会员首破千万 |
| 电商占比 | 线上销售额占比超 50%（2025 Q3 口径） | 电商同比 +32% |

## 1.3 业务结构

山姆会员店（增长引擎）｜大卖场（存量调整）｜电商/云仓（500+ 前置仓）｜配送中心网络（全国供应链区域配送中心）。供应链/履约是支撑高增长的关键能力。

> 📌 **核心结论**：中国区处于高增长期（连续 3 年双位数），山姆扩张带动配送中心网络扩张，供应链/履约人才需求旺盛；对文雪是「外企首选档 + 高增长平台」，但岗位落点在配送中心一线轮岗。

> ✅ **推荐点**：外企 + 零售行业加分 + 管培路径清晰（30 个月到配送中心经理）+ 平台高增长。
> ⚠️ **需要注意**：城市为深圳/北京/全国（非山东）；配送中心一线轮岗强度待确认。

## 2.2 岗位挑战

1. 一线轮岗强度：配送中心运营是 24h/两班倒业态，轮岗期可能涉及早晚班/旺季大促，与「从容节奏」偏好有张力；
2. 多城市调配：全国网络意味着轮岗/定岗城市可能变动，文雪山东属地偏好受限；
3. 履约效率指标压力：库存准确率、订单履约时效、成本控制是硬指标，数据驱动决策要求高（正好是文雪强项）；
4. 管培竞争：山姆/沃尔玛管培生项目吸引力强，同期竞争激烈，需差异化呈现。

## 2.3 晋升路径（推测）

管培生（30 个月）→ 配送中心经理 → 高级运营经理/区域运营总监；或横向转供应链计划、履约、采购。标注：**推测**，基于公开「30 个月到配送中心经理」定位。

# 四、针对文雪的风险和顾虑

## 4.1 城市为深圳/北京/全国，非山东

**为什么是问题**：地点平等原则下，深圳/北京为高生活成本城市放最后考虑；全国可选但具体城市未定，若能分配到非北上广潜力城市则地点分可上调。无住宿/补贴说明，深圳/北京岗实际收入需扣高生活成本。
**如何验证**：投递前确认初始城市与轮岗城市；问是否有配送中心在山东（青岛/济南）或就近可调配。

## 4.2 配送中心一线轮岗强度

**为什么是问题**：物流配送业态两班倒/旺季大促，轮岗期可能早晚班、节假日加班，与「拒绝 996、偏好从容」直接冲突。
**如何验证**：面试直问「管培期排班制度、早晚班比例、旺季加班与调休」；找牛客/脉脉配送中心管培面经确认。

## 4.3 薪资未披露，生活成本需评估

**为什么是问题**：公开仅「五险一金+年底双薪+进阶计划」，具体薪资未披露；深圳/北京生活成本高。
**如何验证**：Offer 阶段确认 base+奖金+进阶计划各阶段薪资；评估是否覆盖目标城市生活成本。

## 4.4 外企英语环境 vs CET-4

**为什么是问题**：外企汇报/系统可能含英文，文雪仅 CET-4。
**如何验证**：面试问「日常工作语言、系统/邮件是否英文、汇报对象」。

## 4.5 管培轮岗后定岗不确定

**为什么是问题**：30 个月轮岗后定岗城市/岗位可能不由自己完全决定，若被派往偏远配送中心则被动。
**如何验证**：面试问「轮岗与定岗机制、是否有意向城市选择权、往届定岗去向」。

## 4.6 无大厂实习，管培面试竞争激烈

**为什么是问题**：管培项目名校生云集，无实习履历易被质疑稳定性与抗压。
**如何验证**：用数据能力差异化（4.5 万条分析、优化模型、ERP 实操），准备 STAR 行为面案例；突出「能在数据上补足一线经验」。

> ⚠️ **额外关注**：沃尔玛中国近年战略向山姆倾斜、大卖场收缩，需确认配送中心岗位归属业务线（山姆 vs 大卖场）与扩张节奏。
