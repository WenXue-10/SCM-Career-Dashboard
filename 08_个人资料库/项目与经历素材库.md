### 1. 社区团购末端网络优化

- **题名变体**（不同简历用过）：社区团购末端网络优化 / 社区团购自提点选址与配送路径优化 / 社区团购自提点布局与配送路径优化
- **方向定位**：需求-资源平衡 / 网络优化 / 产能-需求平衡（简历标题已精简掉定位后缀，定位信息以此为准）
- **时间**：2026.03 – 2026.06 ｜ **角色**：项目负责人
- **课程来源**：供应链建模与仿真期末课程报告（2025.12 完成首版？报告落款 2025.12，素材库原记 2026.03-06 待核）
- **报告原件**：《基于空间优化的多多买菜自提点选址与路径规划研究——以济南历下区某居住小区为核心》→ `报告论文与作品/供应链建模与仿真_多多买菜自提点选址与路径优化_202512.pdf`
- **背景痛点**：多多买菜自提点布局零散、配送效率偏低、老年群体服务适配性不足（济南历下区某居住小区）
- **数据基础**：15 个候选点、日均 345 单真实数据
- **方法**：选址-路径双层优化模型——上层**改进 p-median 模型**（创新纳入年龄分层服务半径约束：老年 600m / 中年 800m / 青年 1000m），下层**带时间窗车辆路径问题（VRPTW）**；融合「年龄-楼层-需求」三维特征，将电梯等待时间纳入目标函数；Python 求解，对比遗传算法/模拟退火（报告含 GA 收敛曲线、优化前后布局图）
- **成果**：
  - 输出「2 核心点 + 4 动态临时点」弹性布局方案
  - 总成本降低 18.7%、老年覆盖率 53.4% → 87.3%、配送时长缩短 22.3%
  - 可响应周末 29.9%、促销日 50.7% 的需求波动
- **岗位侧重**：计划岗强调「供需平衡方法论」；数据岗强调「建模 + Python 求解 + 真实数据」；物流岗强调「末端网络布局」
- **面试深挖点**：p-median 与 VRPTW 的双层耦合怎么处理？年龄分层半径约束的依据？GA 与 SA 为什么选 GA？
