# Skill 1 - 岗位搜集与匹配（文雪求职知识库）

## 输入
JD（文字/图片/链接均可，需自动提取文本内容）。

## 执行
1. 读取 `00_战略与定位/文雪-求职目标画像.md` 第7章评分规则。
2. **补充信息核实**：对 JD 未披露的维度（薪资、双休/加班、培训体系、住宿补贴等）先做轻量检索再打分。来源分级：
   - 🥇 官方来源（官网/官方招聘页/招聘简章/公告）→ 直接采信
   - 🥈 权威第三方（招聘平台标注、OfferShow 晒薪、公开财报/新闻）→ 参考采信
   - 🥉 网络口碑（脉脉/知乎/牛客/员工论坛）→ 仅参考，须标注来源与可信度，不作事实定性
   - 查不到 → 标注「未收录/未披露」，按保守规则给分；禁止编造
3. 按以下维度打分（满分100，具体加减分以画像第7章为准）：
   - 专业匹配（30%）：与供应链计划/采购/物流/数据分析直接相关
   - 技能匹配（25%）：Python/R/SPSS/Excel/ERP/数据可视化，或明确的数据/分析能力要求
   - 氛围与成长（15%）：培训体系、双休、团队氛围（JD未写明时参考补充核实结果）
   - 地点匹配（10%）：目标城市或提供住房/生活补贴
   - 薪资匹配（10%）：月薪8K-15K或实习150-250/天（JD未标注时参考同类岗位公开信息）
   - 行业偏好（10%）：快消/宠物/零售/数据相关加分
4. 判定等级：≥80高，≥70中，＜70低。≥70标记“推荐投递”；＜70且未触发红线 → “🗂️ 备选（可试）”；触发红线 → “❌ 已挂（红线）”。

## 输出预览
- 岗位评分明细表（各维度得分 + 总分 + 等级）；引用补充信息的维度须附【信息来源】
- 结论：推荐/不推荐
- 红线检查结果（是否触发一票否决）

## 自动写入（无需用户确认）
1. 岗位独立笔记（按 `Templates/岗位笔记模板.md` 格式）→ `01_岗位搜集与背调/公司调研/{公司名}/{岗位名}（{方向}）/评分-{公司名}-{岗位名}（{方向}）.md`
2. 汇总表追加一行 → 岗位汇总表
   列：公司名称、岗位名称、城市、匹配度总分、匹配等级、当前状态、投递截止、薪资、岗位链接、背调报告链接、定制简历链接、更新日期
3. 告知：“✅ 已写入知识库；✅ 已更新汇总表”
4. 总分＜70：仍创建笔记并保留在汇总表，frontmatter「当前状态」填 `🗂️ 备选`（低分可试，不判死）；触发红线的岗位填 `❌ 已挂（红线）`。
5. 归档原始材料：将 JD 原始材料（PDF/图片/文本/链接）复制/记录到 `07_原始材料库/{公司名}/{岗位名}（{方向}）/`，创建材料登记笔记 `{材料类型}-{公司名}-{岗位名}（{方向}）-{日期}.md`（frontmatter：公司/岗位/材料类型/来源/发布日期/归档日期/原文件/关联岗位），并在评分笔记 frontmatter 增加 `原始材料: [[...]]` 指向该登记笔记。frontmatter 中 `[[...]]` 值需加双引号，**多个链接必须分行写成 YAML 列表**（每行一个 `"[[...]]"`），禁止把多个 `[[...]]` 合并进同一个字符串（Obsidian 会贪婪解析成一个错误链接），避免「无效属性」与误建文件。

## 路径适配说明（知识库实际结构）
- 岗位汇总表为 `01_岗位搜集与背调/📋 岗位汇总表.md`，由 Dataview 自动读取 `01_岗位搜集与背调/公司调研/{公司名}/{岗位名}（{方向}）/（无方向则省略（{方向}））` 下**含「匹配等级」字段的评分笔记**的 frontmatter 生成（每企业-岗位-方向仅一条；背调报告等其他文件不参与汇总），无需手动维护。执行时把评分结果写入岗位笔记 frontmatter（公司名称、岗位方向、城市、匹配度总分、匹配等级、当前状态、投递截止、薪资、岗位链接、背调报告、定制简历、更新日期），汇总表即自动刷新。

## 全局规则（所有 Skill 通用）
1. 每次执行 Skill，先在对话中输出完整内容预览（Skill 1/2 以「岗位日报」呈现）。
2. Skill 1（评分）与 Skill 2（背调）为自动执行流程：找到岗位后自动评分、背调、写入知识库，无需用户确认。
3. Skill 3（简历）/Skill 4（备考）/Skill 5（复盘）/Skill 6（周报）须先询问“请确认以上内容无误，确认后我将写入知识库并生成 Word 文档。”，用户回复“确认”或“可以”后才写入。
4. Word 排版规范（自动应用）：
   - 封面页：标题 + 公司名 + 岗位名 + 日期 + “内部使用·求职调研”
   - 目录（含超链接，可点击跳转）
   - 页眉：文档名称
   - 页脚：页码（第 X 页 / 共 Y 页）
   - 标题自动编号（一、1.1、1.1.1 三级）
   - 中文宋体 / 英文 Times New Roman，小四，1.5 倍行距
5. 禁止编造信息，无法确认的标注“未收录/未披露”。
6. 禁止在输出中提及“AI助手”或“作为AI”。
7. 执行过程中发现问题（工具异常、规则缺口、数据/文件/链接异常等），即时补充到 `99_系统与规则/求职知识库问题日志.md`（问题/原因/处理/状态），并在对话中告知。
8. 来源日期真实性：材料登记笔记的「发布日期」必须是来源页/资料上明确标注的发布（公告）日期；页面无明确日期填「未确定」；禁止用归档日期/检索日期冒充发布日期、禁止编造日期。「归档日期」为材料录入知识库的日期，仅用于排序/去重。
