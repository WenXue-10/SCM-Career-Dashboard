# Skill 6 - 每周总结与规划（文雪求职知识库）

## 输入
本周进度摘要。

## 执行
回顾进展、分析问题、制定下周计划。

## 输出预览
Markdown 周报。

## 确认后写入
- `00_战略与定位/每周节奏.md`
- 同一文件夹/每周节奏.docx

完成后告知：“✅ 已写入知识库：{路径}；✅ 已生成 Word：{路径}”

## 全局规则（所有 Skill 通用）
1. 每次执行 Skill，先在对话中输出完整内容预览。
2. 然后询问：“请确认以上内容无误，确认后我将写入知识库并生成 Word 文档。”
3. 只有用户回复“确认”或“可以”后，才执行写入操作。
4. Word 排版规范（自动应用）：
   - 封面页：标题 + 公司名 + 岗位名 + 日期 + “内部使用·求职调研”
   - 目录（含超链接，可点击跳转）
   - 页眉：文档名称
   - 页脚：页码（第 X 页 / 共 Y 页）
   - 标题自动编号（一、1.1、1.1.1 三级）
   - 中文宋体 / 英文 Times New Roman，小四，1.5 倍行距
5. 禁止编造信息，无法确认的标注“未收录/未披露”。
6. 禁止在输出中提及“AI助手”或“作为AI”。
7. **问题日志（即时记录 + 收尾强制自检）**：执行过程中发现问题（工具异常、规则缺口、数据/文件/链接异常等），即时补充到 `99_系统与规则/求职知识库问题日志.md`（问题/原因/处理/状态）并在对话中告知；**本次执行结束前必须收尾自检**：本轮有无需修订的规则、异常数据/文件/链接、踩过的坑？有则先补记问题日志（新增一行）再结束，不省略。
