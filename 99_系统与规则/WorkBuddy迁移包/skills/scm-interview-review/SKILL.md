# Skill 5 - 面试复盘（文雪求职知识库）

## 输入
公司名 + 岗位名 + 面试日期 + 面试原始记录。

## 执行
生成复盘报告（亮点/不足/改进），追加错题本。

## 投递追踪 + 拒信归因闭环（Skill 5 附加职责）
1. **投递追踪**：更新投递追踪表（公司/岗位/投递日期/进度/备注），进度含：已投递→筛选中→笔试→一面/二面→offer/拒绝/未通过。追踪表模板见 `Templates/投递追踪表模板.md`。
2. **拒信/未通过归因**：对拒绝或未通过的岗位做**归因分析**——判断主因是简历问题（JD 关键词覆盖不足、匹配度低、ATS 未过）还是面试问题（表达/深挖/反问/岗位理解），给出结论与证据。
3. **回写简历版本**：判定为简历问题 → 提出该岗位简历的具体修改点，并联动 Skill 3 回写对应通用简历版本（A/B/C/D）；判定为面试问题 → 沉淀到错题本，供 Skill 4 下次备考引用。
4. **感谢信**：附**面试后 24 小时感谢信模板**（见 `Templates/面试后感谢信模板.md`），结构含致谢、重述关键匹配点、补充未讲清的价值点。

## 输出预览
复盘报告 Markdown。

## 确认后写入
- `04_实战复盘/面试复盘-{公司}-{岗位}-{日期}.md`
- 同一文件夹/面试复盘-{公司}-{岗位}-{日期}.docx
- 同时追加错题到 `03_笔面试题库/错题本.md`
- 更新 `08_个人资料库/投递追踪表.md`

完成后告知：“✅ 已写入知识库：{路径}；✅ 已生成 Word：{路径}；✅ 已追加错题本”

## 全局规则（所有 Skill 通用）
1. 每次执行 Skill，先在对话中输出完整内容预览。
2. 然后询问：“请确认以上内容无误，确认后我将写入知识库并生成 Word 文档。”
3. 只有用户回复“确认”或“可以”后，才执行写入操作。
4. Word 排版规范（自动应用）：
   - 封面页：标题 + 公司名 + 岗位名 + 日期 + “内部使用·求职调研”
   - 目录（含超链接，可点击跳转）
   - 页眉：文档名称
   - 页脚：页码（第 X 页 / 共 Y 页）
   - 标题自动编号（一、1.1、1.1.1 三级）
   - 中文宋体 / 英文 Times New Roman，小四，1.5 倍行距
5. 禁止编造信息，无法确认的标注“未收录/未披露”。
6. 禁止在输出中提及“AI助手”或“作为AI”。
7. **问题日志（即时记录 + 收尾强制自检）**：执行过程中发现问题（工具异常、规则缺口、数据/文件/链接异常等），即时补充到 `99_系统与规则/求职知识库问题日志.md`（问题/原因/处理/状态）并在对话中告知；**本次执行结束前必须收尾自检**：本轮有无需修订的规则、异常数据/文件/链接、踩过的坑？有则先补记问题日志（新增一行）再结束，不省略。
