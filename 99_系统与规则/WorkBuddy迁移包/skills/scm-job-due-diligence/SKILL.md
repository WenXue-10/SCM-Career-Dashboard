# Skill 2 - 岗位背调分析（文雪求职知识库）

## 固定服务对象
文雪，山东大学供应链管理 2027 届毕业生：
- 沉稳细致、CET-4、在济南读书（非济南本地人）
- 老家四川乐至县，家人目前在宁波
- 会 Python、用友 U8+
- 无大厂实习
- 拒绝 996，北京、上海等生活成本过高、节奏快、压力大的城市不优先考虑
- 偏好生活成本适中、节奏从容的新一线/二线城市

所有报告的【第四部分】【第六部分】必须围绕该画像展开，不得泛泛而谈。

## 企业筛选原则（准入判断依据）
- **外企优先，但不排斥优质国内企业**
  - 外企：细分赛道头部、D 轮后或上市稳健、员工规模 500–2000 人成长型
  - 国内企业：管理规范、有国际化视野、完善应届生培训体系、经营稳健、无强制加班文化
  - 排除：A 轮前极不稳定初创、<100 人无培训体系作坊、大量劳动纠纷负面新闻企业
- 报告【第三部分】开头必须先做**准入判断**：对照画像第 2.5 章「潜力企业筛选标准」及上述原则，给出「符合 / 部分符合 / 不符合」结论，再做综合评分。

## 输入
公司名 + 岗位名（或 JD 文本/图片/链接均可，需自动提取文本内容）。

## 执行流程
1. 读取输入，提取岗位名称、职责、硬性要求。
2. 基于训练数据记忆分析目标公司。知名企业给出基本面判断；不知名或缺少公开信息的小公司，诚实标注“未收录公开信息”，禁止编造公司资料。
3. 按下方六大板块框架生成内容。
4. 无法确认的信息一律标注“未收录/未披露”，禁止编造。

## 报告篇幅
总字数 **4000–6000 字**，必须可直接复制到 Word；禁止为凑字数重复表述。

## 必须输出的六大板块

### 【第一部分】公司基本面
- 一句话搞懂这家公司：干什么的？什么地位？全球/中国布局？
- **核心财务数据**：近 3 年营收/利润/增长（表格）+ 一句「打工人解读」；无数据则标注“未收录”
- 业务结构：各业务线营收占比、毛利率、核心产品（表格）
- 行业地位与竞争格局：市场份额、主要竞品、差异化优势（对比表格）+ 一句「打工人解读」
- 好消息 / 坏消息（用高亮块呈现）

### 【第二部分】岗位专项深度调研
- 岗位基本信息：岗位名称、所属部门、招聘类型、工作地点、薪资范围（未披露写「**未披露（需面试确认）**」）、专业要求、核心技能（表格）
- JD 翻译成人话：逐条解释职责，指出真实工作内容与 JD 话术背后的重点（表格）
- 该岗位所在部门/基地的战略地位：分基地岗位需说明是核心基地还是边缘办事处，有具体数据（投资、产能、员工数）更好
- 岗位挑战：至少 4-5 条，结合岗位实际
- 发展前景与晋升路径：纵向晋升 + 横向转岗 + 行业跳槽价值；合理推断，并明确标注为“推测”

### 【第三部分】公司值不值得去
- 开头先做**准入判断**（见「企业筛选原则」）
- 职场口碑：好评高频词（5-8 个）+ 差评高频词（5-8 个）+ 总结判断
- 加班与工作强度：分岗位类型（研发/制造/职能/办公室）列加班情况、加班费、双休（表格），标注可信度；⚠️ 必须区分产线操作工差评和办公室岗是不同群体
- 薪酬福利：校招薪资表（分地点/学历，标注来源）+ 福利清单 + ✅推荐点 / ❌劝退点；无数据则写“JD/公开信息未披露”
- 文化氛围：沟通风格、层级关系、同事画像、适合/不适合什么人
- 裁员/优化历史：有无大规模裁员？劳资纠纷？岗位安全性评估（标注信息可靠度）
- 综合评价：各维度评分表格（薪资竞争力、工作强度、成长空间、公司稳定性、文化适配度、地域便利性）+ 综合推荐指数 + 综合评分星级（五星制，如 ★★★★☆）+ 「适合谁 / 不适合谁」

### 【第四部分】针对文雪的风险和顾虑
- 结合文雪背景，至少 6-8 条针对性问题（每条以「？」结尾）
- 每条说明“为什么是问题”及“面试/入职时如何验证”
- **必须覆盖**：考研 vs 校招时间冲突、济南属地稳定性、加班承诺落实、无大厂实习如何弥补、内向性格跨部门沟通适配、CET-4 是否影响发展

### 【第五部分】信息溯源
- 表格列出：信息类别、来源、可信度（「权威核实」/「参考性信息」/「网友评价需自行判断」）
- 每条关键信息标注“基于AI训练数据”或“基于JD文件提取”
- 不虚构来源（不编造新闻链接、财报页码、访谈记录）

### 【第六部分】面试前准备
- 5 个“我很懂你们”切入点：必须从真实经历中提取（用友 U8+、社区团购项目、银行数据项目、济南属地、专业课程）；不够 5 个就写 3-4 个，**禁止编造经历**；每个切入点包含「一段可直接说的话 + 为什么能打动面试官」
- 6 个高质量反问：展示深度，薪资/加班等敏感问题放后半段，**优先覆盖「信息缺口清单」中的未查到项**
- 入职核实清单（checkbox）：定级、薪资结构、加班政策、工作地点、试用期 KPI、三方毁约政策（与考研冲突）、五险一金基数、导师/培训

## 报告末尾
- 单独「信息缺口清单」（查不到的关键信息，如第三部分有未查到项）
- 「报告生成日期」+「信息截止日期」

## 深度与质量红线（防止缩水，必须执行）
- **质量范本**：以知识库 `01_岗位搜集与背调/公司调研/比亚迪/计划专员（产能规划、供需平衡-电控济南）/背调报告-比亚迪-*.md` 为标杆，内容量与信息密度不得低于该范本。
- **必须完整呈现**：① 财务数据表（有数据必须列表 + 标注来源）；② JD 逐条「翻译成人话」表格；③ 岗位挑战 ≥3 条；④ 多维度评估表（口碑/加班/薪酬/裁员/培训）；⑤ 针对文雪的风险 ≥6 条，每条含「为什么是问题 + 如何验证」；⑥ 信息溯源表 + 未披露项清单；⑦ 5 个切入点 + 6 个反问 + 入职核实清单；⑧ 第三部分开头准入判断 + 报告末尾信息缺口清单/截止日期。
- **禁止缩水**：禁止用一句话概括替代表格/清单；禁止只写"基于公开检索"而不列具体来源；禁止跳过 JD 翻译表；风险项少于 6 条视为不合格，必须补足。
- **信息要求**：知名企业必须检索最新财务与口碑数据，并注明来源与日期（如"2026-02 财报报道"）；查不到的标注「未收录/未披露」，禁止编造。

## 排版规范
- 开头为封面信息块（公司名、岗位、报告日期、报告性质），并带页眉“📋 内部使用 · 面试调研报告”
- 标题用【】加粗；关键数据**加粗**；对比用表格
- 高亮块：📌核心结论 / ⚠️需要注意 / ✅推荐点 / ❌劝退点
- 评级用五星系统（如 ★★★★☆）
- 末尾附分隔线及页脚

## 输出预览
背调报告自动生成并写入（无需用户确认），摘要并入「岗位日报」呈现；完整报告存于知识库。

## 自动写入（无需用户确认）
- `01_岗位搜集与背调/公司调研/{公司名}/{岗位名}（{方向}）/背调报告-{公司名}-{岗位名}（{方向}）.md`
- 同一文件夹/背调报告-{公司名}-{岗位名}（{方向}）.docx

完成后告知：“✅ 已写入知识库：{路径}；✅ 已生成 Word：{路径}”

## 全局规则（所有 Skill 通用）
1. 每次执行 Skill，先在对话中输出完整内容预览（Skill 1/2 以「岗位日报」呈现）。
2. Skill 1（评分）与 Skill 2（背调）为自动执行流程：找到岗位后自动评分、背调、写入知识库，无需用户确认。
3. Skill 3（简历）/Skill 4（备考）/Skill 5（复盘）/Skill 6（周报）须先询问“请确认以上内容无误，确认后我将写入知识库并生成 Word 文档。”，用户回复“确认”或“可以”后才写入。
4. Word 排版规范（自动应用）：
   - 封面页：标题 + 公司名 + 岗位名 + 日期 + “内部使用·求职调研”
   - 目录（含超链接，可点击跳转）
   - 页眉：文档名称
   - 页脚：页码（第 X 页 / 共 Y 页）
   - 标题自动编号（一、1.1、1.1.1 三级）
   - 中文宋体 / 英文 Times New Roman，小四，1.5 倍行距
5. 禁止编造信息，无法确认的标注“未收录/未披露”。
6. 禁止在输出中提及“AI助手”或“作为AI”。
7. **问题日志（即时记录 + 收尾强制自检）**：执行过程中发现问题（工具异常、规则缺口、数据/文件/链接异常等），即时补充到 `99_系统与规则/求职知识库问题日志.md`（问题/原因/处理/状态）并在对话中告知；**本次执行结束前必须收尾自检**：本轮有无需修订的规则、异常数据/文件/链接、踩过的坑？有则先补记问题日志（新增一行）再结束，不省略。
