## Prompt（直接复制整段）

时间：每天 12:00（每天执行，含周末）
触发内容："执行 Skill 7（自动岗位监控）"
执行要求：
0. 知识库访问（重要）：云端沙箱无法直接访问 D:\Obsidian\SCM-Career，**必须用 Git 仓库模式**——先执行 `git clone https://github.com/WenXue-10/SCM-Career-Dashboard.git` 到工作区，在 clone 内操作（目录结构与 Obsidian 库一致：00_战略与定位/01_岗位搜集与背调/07_原始材料库/99_系统与规则/…）。开工前 `git pull` 拉最新；完成后 `git add -A && git commit -m "auto: Skill7 岗位日报 <日期>" && git push`（push 用已授权的 GitHub MCP 连接器；被拒则先 `git pull --rebase` 再 push）。本地每 10 分钟自动同步会把仓库变更拉回 D:\Obsidian\SCM-Career 并重建网页，无需额外操作。
1. 先读取 clone 内 07_原始材料库、01_岗位搜集与背调/📋 岗位汇总表.md、00_战略与定位/文雪-求职目标画像.md（第 2.5 章潜力标准、第 7 章评分规则）以及记忆文件（如 Skill7_记忆.md，放 clone 内）做去重恢复，避免重复。
2. 按 Skill 7 规则：以画像第 2.5 章「潜力企业筛选标准」动态发掘新企业（大厂子企业/幼年体/小而美外企/赛道好；参考候选线索池，仅初始候选不作为边界），每发掘一家先做初步筛选判断；来源优先级：🥇 企业官网/官方招聘页 → 🥈 招聘软件（BOSS直聘/猎聘/前程无忧/智联/应届生求职网/牛客校招）→ 🥉 其他网页（仅作线索回官方核实）；需登录平台若无 Web Access 则记录"需授权"列入日报待办，不绕过登录；单轮全网搜索 ≤ 10 次，先「发掘→筛选→归档→评分→写入」一批（≥3 个）再扩大；去重 → 归档 07_原始材料库 → Skill 1 自动评分并写评分笔记 → Skill 2 自动背调（每轮上限 3-5 个，质量优先）→ 生成岗位日报；届别核验：JD 发布批次与 2027 届核对，上一届标 ⚠️届别待确认（不标推荐）、模糊标 ⚠️届别待核实；背调报告文件未写入时不得标 ✅已背调（标 ⚠️背调待补充）；来源日期真实性：发布日期须为来源页明确标注的发布日，无则写「未确定」，禁止用归档日期冒充。
3. 网络/工具受限时：能抓的公开来源照常抓取；需登录平台记录"需授权"列入日报待办，不卡住、不编造、不绕过登录；命令被限制时不空转重试，输出完整结构化日报（企业/岗位/地点/薪资/来源/发布日期/届别核验/初步评分/背调/待办）并 commit + push。
4. 本轮完成后：a) 把摘要（新增岗位/评分/背调/待办/问题）写入 clone 内记忆文件 Skill7_记忆.md；b) 在对话中输出完整岗位日报；c) 把日报摘要（3-5 行）追加到 clone 内 01_岗位搜集与背调/📅 岗位日报归档.md（只追加不覆盖、标注日期）；d) git add + commit + push。
5. 写文件：用 Python 写 UTF-8（环境内 python3 通常可用；不可用则用 shell 工具写），同一写入连续失败 2 次即停止重试并记入问题日志/日报；连续 3 分钟无进展先提交已完成的并出日报。
6. 发现问题即时记入 clone 内 99_系统与规则/求职知识库问题日志.md。
提醒：本自动化跑在云端沙箱，电脑关机也能执行；push 到 GitHub 后本地自动同步，网页/手机同步更新。
