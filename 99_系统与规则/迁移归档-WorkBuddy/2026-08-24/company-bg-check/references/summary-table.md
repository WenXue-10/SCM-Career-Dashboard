# 企业岗位汇总表.xlsx 维护

## 文件位置
在当前工作目录 / 项目资料库中查找 `企业岗位汇总表.xlsx`；若不存在则新建。

## 字段（列顺序固定）
| 序号 | 分析日期 | 企业名称 | 岗位名称 | 综合评分(百分制) | 最大加分项 | 最大风险项 | 最终建议 |

- **序号**：整数，自增（= 现有最大序号 + 1），首条为 1
- **分析日期**：YYYY-MM-DD
- **综合评分(百分制)**：0–100 整数
- **最终建议**：如"建议投递 / 谨慎考虑 / 建议放弃"

## 维护流程（每次分析完执行）
1. 先读取历史数据 → 取得现有最大序号
2. 追加新数据（新序号 = 最大序号 + 1）
3. 覆盖保存回原文件

## 调用方式
使用 `scripts/update_summary.py`：

```bash
python scripts/update_summary.py \
  --company "某公司" \
  --position "供应链运营" \
  --score 82 \
  --plus "完善的应届生培训体系" \
  --risk "加班强度偏高" \
  --advice "建议投递" \
  --date "2026-08-21" \
  --path "企业岗位汇总表.xlsx"
```

若未传 `--path`，默认在当前目录查找 / 创建 `企业岗位汇总表.xlsx`。
