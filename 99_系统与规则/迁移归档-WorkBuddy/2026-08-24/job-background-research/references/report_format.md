# 报告格式规范（六板块完整框架）

> 本文件是 SKILL.md 调研框架的**全文细节**。最终报告必须可直接复制到 Word，总字数 **4000–6000 字**，禁止为凑字数重复表述。

## 通用排版规范

1. **封面**：公司名称 + 报告标题 + 日期 + 调研人，用分隔线装饰
2. **页眉**：首页顶部标注「📋 内部使用・面试调研报告」
3. **标题层级**
   - 一级：`【第一部分】XXX`（加粗）
   - 二级：`1.1 XXX`（加粗）
   - 三级：用 `▶` 或 `▪` 前缀
4. **关键数据**：所有数字、百分比、金额用 `**加粗**`
5. **表格**：对比类信息必须用 Markdown 表格
6. **高亮块**（必须用）：
   - `📌 核心结论：XXX`
   - `⚠️ 需要注意：XXX`
   - `✅ 推荐点：XXX`
   - `❌ 劝退点：XXX`
7. **评级**：五星系统（★★★★☆，按维度给星）
8. **分隔**：每个板块结尾用 `---`
9. **信息缺口**：查不到的关键信息，报告末尾单独列「信息缺口清单」，并在第六部分反问中优先覆盖

---

## 【第一部分】公司基本面

**1.1 一句话搞懂这家公司**：干什么的？什么地位？创始人？全球 / 中国布局？
**1.2 核心财务数据**：近 3 年营收 / 利润 / 增长（表格）+ 一句「打工人解读」
**1.3 业务结构**：各业务线营收占比、毛利率、核心产品（表格）
**1.4 行业地位与竞争格局**：市场份额、主要竞品、差异化优势（对比表格）+ 一句「打工人解读」
**1.5 好消息 / 坏消息**：✅好消息 + ❌坏消息，分栏列出

---

## 【第二部分】岗位专项深度调研

**2.1 岗位基本信息**：岗位名称、所属部门、招聘类型、工作地点、薪资范围（未披露写「**未披露（需面试确认）**」）、专业要求、核心技能（表格）
**2.2 JD 翻译成人话**：JD 每条要求 → 实际工作内容、难度、学习价值（表格）
**2.3 该岗位所在部门 / 基地的战略地位**：分基地岗位需说明是核心基地还是边缘办事处，有具体数据（投资、产能、员工数）更好
**2.4 岗位核心挑战**：至少 4–5 点，结合行业特性和公司实际
**2.5 发展前景与晋升路径**：纵向晋升 + 横向转岗 + 行业跳槽价值

---

## 【第三部分】公司值不值得去（❗重点，打工人视角）

**先做准入判断**：对照【企业筛选原则】，该公司是否符合纳入标准？给出「符合 / 部分符合 / 不符合」结论，再展开评分。

**3.1 职场口碑**：好评高频词（5–8 个）+ 差评高频词（5–8 个）+ 总结判断
**3.2 加班与工作强度**：各岗位类型（研发 / 制造 / 职能 / 办公室）加班情况、加班费、双休（表格），标注可信度。⚠️**必须区分产线操作工差评和办公室岗是不同群体**
**3.3 薪酬福利**：校招薪资表（分地点 / 学历，标注来源）+ 福利清单 + ✅推荐点 / ❌劝退点
**3.4 文化氛围**：沟通风格、层级关系、同事画像、适合 / 不适合什么人
**3.5 裁员 / 优化历史**：有无大规模裁员？劳资纠纷？岗位安全性评估
**3.6 综合评价**：各维度评分表格（薪资竞争力、工作强度、成长空间、公司稳定性、文化适配度、地域便利性）+ 综合推荐指数 + 「适合谁 / 不适合谁」

---

## 【第四部分】我的风险和顾虑（个人化，专属文雪）

结合用户背景逐条列出，至少 **6–8 条**，每条以「？」结尾，包含具体分析。
**必须覆盖**：考研 vs 校招时间冲突、济南属地稳定性、加班承诺落实、无大厂实习如何弥补、内向性格跨部门沟通适配、CET-4 是否影响发展。

格式示例：

> **1. 考研 vs 校招：怎么并行？**
> 具体分析……

---

## 【第五部分】信息溯源

表格列出：信息类别、来源、可信度（「权威核实」/「参考性信息」/「网友评价需自行判断」）。

---

## 【第六部分】面试前准备

**6.1 「我很懂你们」切入点（3–5 个）**

- 必须从用户真实经历中提取（用友 U8+、社区团购项目、银行数据项目、济南属地、专业课程）
- 不够 5 个就写 3–4 个，**禁止编造经历**
- 每个切入点包含：一段可直接说的话 + 为什么能打动面试官

**6.2 高质量反问问题（至少 6 个）**

- 展示深度的问题，薪资 / 加班等敏感问题放后半段
- 必须优先覆盖「信息缺口清单」中的未查到项

**6.3 入职前必须核实的清单**

- checkbox 形式：定级、薪资结构、加班政策、工作地点、试用期 KPI、三方毁约政策（与考研冲突）、五险一金基数、导师 / 培训

---

## 报告末尾

- 单独「信息缺口清单」（如第三部分有未查到项）
- 「报告生成日期」+「信息截止日期」

## Word 文档自动生成规范（优先级高于上面手动指南）

> 确认出报告后，直接用 `scripts/gen_report_docx.py` 生成 Word，不要再手动排版。
>
> ⚠️ **预览阶段不保存 .md 文件**：第三步把完整报告以 **Markdown 文本直接输出在对话中**供预览即可，**不要**把预览内容写成工作区里的 `.md` 文件。用户确认后，再把报告正文写入**系统临时目录**（如 `~/AppData/Local/Temp/` 或 `/tmp/`）的临时 `.md`，调用脚本生成 docx 到工作区，**生成完成后立即删除该临时文件**——最终工作区只留下 `.docx` 与 `.xlsx`，不残留预览 `.md`。

### 页面与段落（ins 风 / 可爱主题）

- 页边距：上 2.5cm、下 2.5cm、左 3cm、右 3cm
- **段落间距收紧**：正文行距 **1.25 倍**（原 1.5），一级标题段前 8pt / 段后 6pt（原 12/6），二级标题段前 6pt / 段后 4pt
- 字体：标题与正文统一用 **微软雅黑（eastAsia=微软雅黑）**，正文 10.5pt，**一级标题 18pt 加粗（带玫瑰色装饰底线）、二级标题 15pt 加粗**
- 整体气质：低饱和莫兰迪色 + 奶白底，柔和、干净、带一点可爱的圆润感（不用沉闷的深蓝黑体）

### ins 风配色板（柔和低饱和）

| 用途 | 色值 | 说明 |
|---|---|---|
| 主色（一级标题 / 封面公司名） | `#B5838D` 干玫瑰粉 | 温柔但清晰 |
| 二级标题 | `#6D9A8E` 薄荷绿灰 | 与主色互补 |
| 分隔线 / 目录点线 | `#E0C3B5` 浅陶土 | 暖调柔和 |
| 表格表头底 | `#F3E3DC` 浅奶粉 | 配深字 `#7A5C61` |
| 表格表头字 | `#7A5C61` 深玫瑰 | 不用纯黑 |
| 高亮块 📌 浅灰绿 | `#EAF2EC` | |
| 高亮块 ⚠️ 浅鹅黄 | `#FBF3D9` | |
| 高亮块 ✅ 浅薄荷 | `#E3F0E8` | |
| 高亮块 ❌ 浅粉红 | `#FBE3E6` | |
| 正文 / 普通字 | `#3F3A3A` 暖灰黑 | 比纯黑柔和 |

### 目录页（必须，可点击跳转）

- 封面之后、正文之前插入独立「📑 目录」页
- 收录所有一级标题（`【第一部分】`～`【第六部分】` 以及「信息缺口清单」），每条带小图标
- **每个一级标题段落插入书签（bookmark），目录项用内部超链接（hyperlink anchor）指向该书签**，实现打开即可点击跳转
- 目录项格式示例：`🌸 【第一部分】公司基本面` → 点击跳转到对应章节
- 章节标题的图标建议：第一部分💼、第二部分📋、第三部分🔍、第四部分💡、第五部分📚、第六部分🎯、信息缺口⚠️

### 封面页

- 公司名 20pt 微软雅黑加粗居中（主色）；报告标题 15pt 居中（二级色）；岗位 11pt 居中
- 一条浅陶土色分隔线；下方居中排调研人 / 报告日期 / 信息截止日期
- 首页页眉：`📋 内部使用・面试调研报告`（居中、灰色小字）

### 表格（精致风，必须）

- **表头**：实心干玫瑰粉底（`#B5838D`）+ **白色加粗字**，居中，比浅奶粉底更显质感
- **表体**：斑马纹（奇数行浅玫瑰 `#FBF4F1`、偶数行白），左侧对齐，柔和不刺眼
- **边框**：统一柔和玫瑰灰 `#D8C3BC` 细线（非纯黑粗框），整体更精致
- **列宽**：默认加宽；含「建议 / 风险 / 加分 / 原因 / 分析 / 说明 / 评价」等字样的列自动再放宽（尤其「建议」列要明显更宽，保证长句不挤）
- 高亮块（📌/⚠️/✅/❌）：整段浅色底纹（按上方配色表），左侧略缩进

> 以上表格样式由 `scripts/gen_report_docx.py` 自动实现，无需手动调。

### 调用方式

```
python scripts/gen_report_docx.py <临时报告.md> <输出.docx>
```

- 输入 `.md` 来自系统临时目录（非工作区持久文件）；输出 `.docx` 落到工作区，**命名必须带方向**：`【调研报告】公司名-岗位名(方向)-日期.docx`（例：`【调研报告】比亚迪-计划专员(电控济南)-20260821.docx`）
- 脚本会自动：解析六板块 → 生成封面 → 生成可点击目录页 → 渲染正文（一级 18pt 加粗带装饰线 / 二级 15pt 加粗 / 精致风表格 / 高亮块 / 分隔线）→ 落盘
- 落盘后删除临时 `.md`，保持工作区整洁

## 企业岗位汇总表样式规范（ins 风，与 Word 报告一致）

> `企业岗位汇总表.xlsx` 不是裸数据表，也要精致化。样式由 `scripts/append_summary.py` 自动套用（追加 / 更新 / `--restyle` 都会触发），无需手动调。

### 配色与字体

- 表头：干玫瑰粉填充 `#B5838D` + **白色加粗字 12pt（微软雅黑）** + 居中
- 数据行：斑马纹（奇数行白、偶数行极浅粉 `#F7F0EE`）+ 微软雅黑 10.5pt + 自动换行 + 垂直居中
- 边框：浅陶土细线 `#E8D5CD`，整体柔和不刺眼
- 隐藏网格线、首行冻结、开启自动筛选

### 列宽（尤其「最终建议」最宽）

| 列 | 字段 | 宽度 |
|---|---|---|
| A | 序号 | 6 |
| B | 分析日期 | 13 |
| C | 企业名称 | 16 |
| D | 岗位名称 | 28 |
| E | 综合评分(百分制) | 12 |
| F | 最大加分项 | 30 |
| G | 最大风险项 | 34 |
| H | **最终建议** | **46（最宽）** |

- 序号 / 分析日期 / 综合评分 三列居中，其余左对齐

### 维护命令

```bash
# 追加一行（自动带样式）
python scripts/append_summary.py 企业岗位汇总表.xlsx \
  --company "比亚迪 BYD" --role "计划专员·产能规划/供需平衡·电控济南" \
  --score 68 --pro "..." --risk "..." --advice "..."

# 更新已有公司记录（按企业名称匹配，不重复追加）
python scripts/append_summary.py 企业岗位汇总表.xlsx --update --company "比亚迪 BYD" ...

# 仅重新应用精致样式（不改动数据）
python scripts/append_summary.py 企业岗位汇总表.xlsx --restyle
```
