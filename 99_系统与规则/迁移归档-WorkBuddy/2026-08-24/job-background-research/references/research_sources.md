# 调研工具映射与信息源清单

> 角色设定中提及的 `general_search` 与 `seed_finance_search` 并非真实工具名，本文件将其映射到 WorkBuddy 实际可用的能力，并列出具体检索平台。

## 一、通用检索（对应 `general_search`）

用途：企业背景、职场口碑、行业新闻、裁员 / 加班相关文章、JD 解读素材。

| 角色原词 | 实际能力 | 说明 |
|---|---|---|
| `general_search` | `WebSearch` | 全网检索，优先中文结果 |
| — | `WebFetch` | 抓取具体页面（官网、新闻、脉脉 / 看准文章）做深度提取 |
| — | 读本地文件 | 用户上传的 JD / 公司资料 / 历史报告 |

**重点平台清单：**
- 企业官网 / 投资者关系页（IR）
- 看准网、脉脉职言、知乎、小红书（职场口碑、加班、裁员）
- 36氪、亿欧、晚点 LatePost、第一财经（行业新闻）
- 黑猫投诉、裁判文书网、企查查 / 天眼查（纠纷、经营异常）

## 二、上市公司财报与研报（对应 `seed_finance_search`）

用途：近 3 年营收 / 利润 / 增长、股价、研报、业务结构。**仅适用于上市公司**；非上市公司诚实标注「未查到公开财报」。

| 角色原词 | 实际能力 | 说明 |
|---|---|---|
| `seed_finance_search` | `WebSearch` + `WebFetch` | 搜「公司名 年报 营收 净利润」「公司名 研报」 |
| `seed_finance_search` | `wb-finance-skill` | 金融 / 财报 / 估值类深度检索（仅上市公司、确有需要时调用） |

**重点来源：**
- 交易所公告 / 公司年报（巨潮资讯网、公司 IR）
- 东方财富、同花顺、雪球（财务数据、股价、研报摘要）
- 券商研报（Wind / 慧博，公开摘要优先）

## 三、诚实标注规则

- 查不到的信息必须写「**未查到公开信息**」，禁止编造
- 网友评价类必须标注「网友评价，仅供参考」
- 参考薪资区间必须标注来源 + 「仅供参考，非该公司确定薪资」
- 所有财务 / 口碑结论尽量附来源，便于第五部分「信息溯源」填写可信度

## 四、调研节奏建议

1. 先用 `WebSearch` 广撒网（公司名 + 财报 / 口碑 / 加班 / 裁员 各一组）
2. 对关键页面（官网 IR、看准差评集中的帖子）用 `WebFetch` 深挖
3. 上市公司补一轮财报 / 研报检索
4. 仍缺口的项，集中列入「信息缺口清单」，在反问问题中覆盖
